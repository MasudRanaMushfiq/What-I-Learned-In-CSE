

# What I learned throughout my CSE degree

### B.Sc. Engineering in CSE · University of Rajshahi · Session 2021–2022

> **Purpose:** A personal documentation of _what I learned throughout my CSE degree_ — written year by year, so that reading one note brings back everything that year taught me. Each note is a  **abstract overview** of a full academic year, not a detailed course textbook.

---

## 🎯 What This Is

This is a documentation of the CSE journey — a structured answer to the question _"what did I actually learn in four years of Computer Science Engineering?"_

Each year-wise note is written as a **concise abstract** of all courses in that year. It does not replace the full course notes or textbooks — it distills them. The goal is that reading a year note once is enough to bring back the core ideas, key concepts, and mental map of everything covered that year.

- **Abstract, not exhaustive** — key ideas and concepts, not every detail of every topic
- **"What we learned" focused** — written to document and recall, not to teach from scratch
- **Revision-ready** — structured so that a single read refreshes everything in your mind
- **Connected thinking** — shows how courses in the same year relate to each other (e.g., how Discrete Math feeds into Algorithms, how C fundamentals lead to Data Structures)

> ⚠️ **Note:** These year-wise documents are **not full course notes**. They are abstract summaries — a high-level record of what was learned. For detailed topic coverage, refer to the individual course files in the semester folders.

## 📖 Year-wise Revision Notes

### 📗 1st Year — Part I (Semesters 1.1 + 1.2)

**Covers 17 (Theory and Lab) courses across 2 semesters · 40 credits total**

|Semester|Courses Covered|
|:--|:--|
|1.1|Technical English · Calculus · Chemistry · Basic Electronics · Computer Systems · Structural Programming (C)|
|1.2|Engineering Economics · Statistics for Engineers · Co-ordinate Geometry · Basic Electricity · Digital Electronics · Object Oriented Programming (Java)|

**What you'll be able to recall after reading:**
- How to write and reason about C programs — variables, control flow, functions, pointers, memory
- Core OOP concepts in Java — classes, objects, inheritance, polymorphism, encapsulation
- Foundational mathematics — derivatives, integrals, coordinate geometry, complex variables
- How digital circuits work — logic gates, Boolean algebra, flip-flops, combinational and sequential circuits
- Basic electronics — diodes, transistors, amplifiers
- Statistical reasoning — probability, distributions, hypothesis testing

### 📘 2nd Year — Part II (Semesters 2.1 + 2.2)

**Covers 20 (Theory and Lab) courses across 2 semesters · 40 credits total**

|Semester|Courses Covered|
|:--|:--|
|2.1|Industrial Management · Theory of Statistics · Differential Equations · Digital System Design · **Data Structure** · Discrete Mathematics|
|2.2|Cyber & IP Law · Numerical Methods · Linear Algebra · **Theory of Computation** · **Design and Analysis of Algorithms** · Computer Architecture|

**What you'll be able to recall after reading:**

## ✍️ How to Use These Notes

These notes serve as an **abstract record and revision aid** — not a substitute for full course study.
1. **Before an exam** — Read the year note to refresh the big picture, then dive into specific course files from github for detail.
2. **For job interviews** — Skim the **Key Courses Across All Years** notes to recall DSA, DBMS, OS, and Networks at a conceptual level.
3. **For viva or board exam** — The year note gives you the vocabulary and key points; it is written in a direct, answerable format.
4. **For project context** — If you are building something (e.g., a web app with a database), the 3rd year note reconnects DBMS + Web Engineering + OS ideas quickly.
5. **As a record** — Long after graduation, these notes answer the question _"what did I actually study in my CSE degree?"_ in a way that a file full of scattered notes never could.
