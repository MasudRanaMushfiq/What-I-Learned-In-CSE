

# Software Engineering Lab

### Course Information
**Course:** CSE 3112 (Software Engineering Lab)
**Course Type:** Laboratory Work, 1 Credit
**Prerequisite:** CSE1222: Object Oriented Programming Lab, CSE2122: Data Structure Lab, CSE2222: Design and Analysis of Algorithms Lab

### Instructor
Mr. Kazi Jahidur Rahman, Assistant Professor, Dept. of CSE, University of Rajshahi

---

### Course Motivation
> To Demonstrate the skills and processes needed to complement technical understanding of software products in order to make you a more effective software developer in an engineering team.

---

## Lab Experiments

| # | Experiment |
| - | ----------------------------------------------------------------------------------------------------------------- |
| 1 | Analyze requirements on a specific problem and produce SRS. |
| 2 | Produce architectural design for the produces SRS document. |
| 3 | Create UML diagram and detail design. |
| 4 | Write Unit Test for each and every module. |
| 5 | Write Code in predefined object-oriented programming language. |
| 6 | Deploy code on server and maintain for further changes. |

### Instructor
Dr. Md. Saiful Islam, Professor, Dept. of CSE, University of Rajshahi

---

### Course Motivation
> To enlighten the student with knowledge base in compiler design and its applications.

---

## Lab Experiments

| #   | Experiment                                                                                                                                                                                           |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| 8   | Write a program to justify if an English sentence is syntactically valid according to Chomsky Normal Form.                                                                                           |
| 9   | Write a program to implement a shift reducing parsing.                                                                                                                                               |
| 10  | Write a program to check the validity of a C++ expression derived by a specific grammar.                                                                                                             |
